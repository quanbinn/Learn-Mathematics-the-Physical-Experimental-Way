# 四阶线

1. 四阶线的通用方程为：0 = αy⁴ + βy³x + γy²x² + δyx³ + εx⁴ + ζy³ + ηy²x + θyx² + ιx³ + κy² + λyx + μx² + νy + ξx + ο。用组合数学的观点，含有 y 的项分别为：αy⁴, βy³x, γy²x², δyx³, ζy³, ηy²x, θyx², κy², λyx, νy，一共有 2¹⁰−1 = 1023 种组合。不含有 y 的项分别为：εx⁴, ιx³, μx², ξx, ο，一共有 2⁵−1 = 31 种组合。

2. 把含有 y 的项放在等式的左边，把不含有 y 的项放在等式的右边，那么一共有 1023 × 31 = 31713 种组合，即 31713 个等式（每个等式形如“含 y 组合 = 不含 y 组合”）。
