# 四阶线

1. 四阶线的通用方程为：
0 = αy⁴ + βy³x + γy²x² + δyx³ + εx⁴ + ζy³ + ηy²x + θyx² + ιx³ + κy² + λyx + μx² + νy + ξx + ο。
用组合数学的观点，含有 y 的项分别为：αy³, βy²x, γyx², εy², ζyx, θy，一共有 63 种组合，分别为：
- αy³; βy²x; γyx²; εy²; ζyx; θy;
- αy³+βy²x; αy³+γyx²; αy³+εy²; αy³+ζyx; αy³+θy; βy²x+γyx²; βy²x+εy²; βy²x+ζyx; βy²x+θy; γyx²+εy²; γyx²+ζyx; γyx²+θy; εy²+ζyx; εy²+θy; ζyx+θy;
- αy³+βy²x+γyx²; αy³+βy²x+εy²; αy³+βy²x+ζyx; αy³+βy²x+θy; αy³+γyx²+εy²; αy³+γyx²+ζyx; αy³+γyx²+θy; αy³+εy²+ζyx; αy³+εy²+θy; αy³+ζyx+θy; βy²x+γyx²+εy²; βy²x+γyx²+ζyx; βy²x+γyx²+θy; βy²x+εy²+ζyx; βy²x+εy²+θy; βy²x+ζyx+θy; γyx²+εy²+ζyx; γyx²+εy²+θy; γyx²+ζyx+θy; εy²+ζyx+θy;
- αy³+βy²x+γyx²+εy²; αy³+βy²x+γyx²+ζyx; αy³+βy²x+γyx²+θy; αy³+βy²x+εy²+ζyx; αy³+βy²x+εy²+θy; αy³+βy²x+ζyx+θy; αy³+γyx²+εy²+ζyx; αy³+γyx²+εy²+θy; αy³+γyx²+ζyx+θy; αy³+εy²+ζyx+θy; βy²x+γyx²+εy²+ζyx; βy²x+γyx²+εy²+θy; βy²x+γyx²+ζyx+θy; βy²x+εy²+ζyx+θy; γyx²+εy²+ζyx+θy;
- αy³+βy²x+γyx²+εy²+ζyx; αy³+βy²x+γyx²+εy²+θy; αy³+βy²x+γyx²+ζyx+θy; αy³+βy²x+εy²+ζyx+θy; αy³+γyx²+εy²+ζyx+θy; βy²x+γyx²+εy²+ζyx+θy;
- αy³+βy²x+γyx²+εy²+ζyx+θy。

不含有 y 的项分别为：δx³, ηx², ιx, κ，一共有 15 种组合，分别为：
- δx³; ηx²; ιx; κ;
- δx³+ηx²; δx³+ιx; δx³+κ; ηx²+ιx; ηx²+κ; ιx+κ;
- δx³+ηx²+ιx; δx³+ηx²+κ; δx³+ιx+κ; ηx²+ιx+κ;
- δx³+ηx²+ιx+κ。

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义函数
def F(x, y):
    return y**3 + x * y**2 + x**2 * y + 6

# 创建网格
x = np.linspace(-5, 5, 400)
y = np.linspace(-5, 5, 400)
X, Y = np.meshgrid(x, y)
Z = F(X, Y)

# 画等高线 F=0
plt.figure(figsize=(8, 6))
plt.contour(X, Y, Z, levels=[0], colors='blue', linewidths=2)
plt.axhline(0, color='black', linewidth=0.5)
plt.axvline(0, color='black', linewidth=0.5)
plt.xlabel('x')
plt.ylabel('y')
plt.title('Curve: $y^3 + xy^2 + x^2 y + 6 = 0$')
plt.grid()
plt.axis('equal')
plt.show()
```
