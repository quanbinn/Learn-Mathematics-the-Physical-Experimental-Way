# 二阶线

1. 二阶线的通用方程为： 0 = α + βx + γy + δx² + εxy + ζy²。用组合数学的观点，含有 y 的项分别为：γy, εxy, ζy², 一共有7种组合, 分别为: 
- γy, εxy, ζy²,
- γy+εxy, γy+ζy², εxy+ζy², 
- γy+εxy+ζy²。

不含有 y 的项分别为：α, βx, δx², 一共有7种组合，分别为：
- α, βx, δx², 
- α+βx, α+δx², βx+δx², 
- α+βx+δx²。

2. 把含有 y 的项放在等式的左边，把不含有 y 的项放在等式的右边，那么一共有49种组合。等式如下：
