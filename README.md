**某些最难几何问题的简易解法**

**作者 L. 欧拉**

---

1. 在每个三角形中通常考虑四个点，它们在几何学中常被考察。

1. 三条垂线的交点，即从各个角向对边所作的垂线。

2. 三条直线的交点，即从各个角平分对边的直线；此点同时是三角形的重心。

3. 三条直线的交点，即平分各个角的直线，在此点有三角形的内切圆圆心。

4. 三条直线的交点，即垂直于各边且平分它们的直线，在此点可找到三角形外接圆的圆心。

5. 从这四个点中，若任意给定三个点的位置，三角形显然由此确定，除非这些点重合于一处，这在等边三角形中发生，所有等边三角形同样满足此问题。

**解法**

$$FG^2 = (AQ-AR)^2 + (QF-RG)^2$$
$$FH^2 = (AQ-AS)^2 + (QF-SH)^2$$
$$GH^2 = (AR-AS)^2 + (RG-SH)^2$$

$$a + b + c = p;\quad ab + ac + bc = q \quad\text{且}\quad abc = r$$

以便代替边我现在将这三个量 $p$、$q$ 和 $r$ 引入计算中，它们与所有边同等相关。由此由于：

$$aa + bb + cc = pp - 2q;\quad aabb + aacc + bbcc = qq - 2pr$$
$$a^4 + b^4 + c^4 = p^4 - 4ppq + 2qq + 4pr$$

面积A如此表达：

$$AA = \frac{1}{16} p(-p^3 + 4pq - 8r) = -\frac{p^4}{16} + \frac{1}{4} ppq - \frac{1}{2} pr$$

其为

$$y = \frac{3(kk - 2ff) \pm k\sqrt{3(4ff - kk)}}{2}$$

且所求三角形的三个边是：

$$a = \frac{3(kk - 3ff)\sqrt{3}}{2\sqrt{4ff - kk}} + \frac{1}{2} k$$
$$b = \frac{3(kk - 2ff)\sqrt{3}}{2\sqrt{4ff - kk}} - \frac{1}{2} k$$
$$c = \frac{3ff\sqrt{3}}{\sqrt{4ff - kk}}$$
